# 文字起こしアプリ

音声・動画ファイルを日本語で文字起こしするデスクトップアプリです。処理はすべて自分のPC上で行い、音声データは外部に送りません。

対応ファイル: .mov .mp4 .m4a .wav .mp3

## 動作環境

| 環境 | 使うエンジン | 備考 |
|---|---|---|
| Mac(Apple Silicon: M1以降) | mlx-whisper | ffmpeg が必要 |
| Windows(NVIDIA GPU) | faster-whisper + CUDA | GPU のドライバが必要 |
| Windows(GPUなし)、Intel Mac | faster-whisper(CPU) | 動くが遅い |

どの環境でも Python 3.10 以上が必要です。

## 事前準備

Mac(Apple Silicon)
1. Python 3 を入れます(https://www.python.org/downloads/)。
2. ffmpeg を入れます。Homebrew があれば `brew install ffmpeg` で入ります。

Windows
1. Python 3 を入れます(https://www.python.org/downloads/)。インストーラの最初の画面で「Add python.exe to PATH」にチェックを入れてください。
2. NVIDIA のグラフィックドライバを最新にします。CUDA Toolkit の別途インストールは不要です(必要なライブラリは初回セットアップで入ります)。

## 起動

このフォルダを clone またはダウンロードして、次のファイルをダブルクリックします。

- Mac: 文字起こしを起動.command
- Windows: 文字起こしを起動.bat

初回だけ、仮想環境の作成とライブラリのインストールが自動で走ります。数分かかり、その間は黒い画面(ターミナル)が開いたままです。2回目以降はすぐ起動します。

モデルは初めて使うときにダウンロードされます(medium で約1.5GB)。その間もアプリは止まって見えますが、そのまま待ってください。

## 使い方

1. ファイルをウィンドウにドラッグ&ドロップするか、「ファイルを選択」で選びます。
2. モデルサイズを選びます。初期値は medium です。
3. 「文字起こし開始」を押します。
4. 終わると結果が表示されます。「テキストを保存」か「クリップボードにコピー」で取り出せます。

モデルサイズの目安

| サイズ | 速さ | 精度 | 目安 |
|---|---|---|---|
| small | 速い | 低め | 動作確認、短い音声 |
| medium | ふつう | ふつう | 初期値 |
| large-v3-turbo | medium と同程度 | 高い | 精度を優先したいとき |

実行中の文字起こしは途中で止められません。「キャンセル」は結果の表示を取り消すだけです。

## Web版(ブラウザから使う)

GPU のあるPCでサーバーを起動しておき、同じネットワークの別の端末(Mac、スマホなど)のブラウザから文字起こしできます。

1. サーバーにするPCで Webを起動.bat をダブルクリックします。
2. 「Password」と聞かれたら、パスワードを入力します。空のまま Enter を押すとパスワードなしです。
3. 黒い画面に出た URL をブラウザで開きます。同じPCなら `http://localhost:6100`、別の端末なら `http://<そのPCのIPアドレス>:6100` です。
4. ファイルをドラッグ&ドロップ(または選択)すると、順番に処理されます。複数入れても同時には処理せず、1件ずつ進みます。
5. 終わった結果は画面に表示され、コピーとテキスト保存ができます。

止めるときは黒い画面を閉じます。結果はサーバーのメモリにだけ残るので、止めると消えます。アップロードしたファイルは、処理が終わると削除されます。

別の端末から開くときは、初めに Windows のファイアウォールの確認画面が出ます。「プライベートネットワーク」を許可してください。

ポートは環境変数 `MOJI_PORT` で変えられます(初期値 6100)。6000 番は X11 用の予約番号で、Chrome と Firefox が接続を拒否するため使えません。

インターネットには公開しないでください。パスワードは通信が暗号化されない状態で送られます。自宅や社内の信頼できるネットワークの中だけで使ってください。

## うまく動かないとき

Mac で「開発元を検証できません」と出る場合は、ファイルを右クリックして「開く」を選びます。ZIP でダウンロードした場合に出ます。git clone で取得した場合は通常出ません。

Mac で ffmpeg のエラーが出る場合は、`brew install ffmpeg` を実行してください。

Windows で `cudnn` や `cublas` の DLL が読み込めないというエラーが出る場合は、次を試します。

1. NVIDIA ドライバを更新する。
2. このフォルダの `venv` を削除してから、もう一度 文字起こしを起動.bat を実行する(ライブラリが入り直ります)。

Windows で GPU が使われているかは、文字起こし中にタスクマネージャーの「パフォーマンス」タブで GPU の使用率が上がるかで確認できます。GPU が見つからない場合は自動で CPU に切り替わり、遅くなります。

## 開発者向け

テストは次のコマンドで動かします。

```
pip install -r requirements-dev.txt
pytest
```
