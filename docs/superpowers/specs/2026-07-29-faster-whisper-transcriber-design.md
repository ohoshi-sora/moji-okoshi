# faster-whisper 文字起こしデスクトップアプリ 設計書

- 日付: 2026-07-29
- 対象: macOS (Apple Silicon) デスクトップGUIアプリ

## 目的

Zoomの録画ファイル(.mov / .mp4)やApple ボイスメモの音声ファイル(.m4a)を
ドラッグ&ドロップで読み込み、faster-whisperで日本語の文字起こしを行い、
プレーンテキストとして保存できるデスクトップアプリを作る。

## スコープ

含む:
- 1ファイルずつのドラッグ&ドロップ/手動選択による読み込み
- faster-whisperによる日本語文字起こし(言語固定)
- 文字起こし結果をリアルタイムでテキストエリアに表示
- プレーンテキスト(.txt)としての保存、クリップボードへのコピー
- モデルサイズの選択(small / medium / large-v3)

含まない(将来の拡張候補として明記するのみ):
- 複数ファイルのバッチ/キュー処理
- SRT/VTTなどタイムスタンプ付き出力
- 話者分離(スピーカーラベル)
- 特定フォルダの自動監視による取り込み

## 前提・制約

- 対象Macは Apple Silicon (M系)。faster-whisper(CTranslate2)はMetal/GPUアクセラレーションに
  未対応のため、CPU推論(`device="cpu"`, `compute_type="int8"`)を用いる。
- 音声/動画のデコードはfaster-whisperが内部で利用するPyAVに任せ、
  ffmpeg抽出処理を独自に実装しない(.mov/.mp4/.m4aを直接読み込み可能)。
- 文字起こし対象は日本語中心のため、`language="ja"`に固定し、
  言語自動検出のオーバーヘッドと誤検出リスクを避ける。

## アーキテクチャ

```
┌─────────────────────────────────────────┐
│  MainWindow (PySide6)                    │
│  - ドラッグ&ドロップ / ファイル選択ボタン  │
│  - モデルサイズ選択 (dropdown)            │
│  - 実行ボタン / 進捗バー                 │
│  - 結果表示 (QTextEdit, 読み取り専用)     │
│  - 保存ボタン (.txt書き出し)              │
└───────────────┬───────────────────────────┘
                │ シグナル/スロット
┌───────────────▼───────────────────────────┐
│  TranscribeWorker (QThread)               │
│  - faster-whisper WhisperModel をロード    │
│  - セグメントごとに文字起こし → 途中経過を  │
│    シグナルでUIに送る                     │
└───────────────┬───────────────────────────┘
                │
┌───────────────▼───────────────────────────┐
│  faster-whisper (CTranslate2)             │
│  - 音声/動画ファイルを直接デコード(PyAV)   │
│  - 言語固定: ja                            │
└─────────────────────────────────────────────┘
```

単一のPythonプロセス内でGUIとモデル推論が完結する(プロセス間通信なし)。
モデル推論はUIスレッドをブロックしないよう別スレッド(QThread)で実行する。

## コンポーネント詳細

### MainWindow
- ドラッグ&ドロップ領域 + 「ファイルを選択」ボタン
  - 対応拡張子: `.mov` `.mp4` `.m4a` `.wav` `.mp3`
  - 非対応拡張子はドロップ時点で弾いてダイアログ表示
- モデルサイズ選択: `small` / `medium` / `large-v3`
  - デフォルトは `medium`(Apple Silicon CPU上での速度と精度のバランスを優先)
- 「文字起こし開始」ボタン、進捗バー
  - 進捗は現在処理中セグメントの`end`時刻を音声全体長で割った概算値
- 結果表示エリア(`QTextEdit`、読み取り専用)
  - 生成中のセグメントをリアルタイムで追記表示
- 「テキストを保存」「クリップボードにコピー」ボタン
- キャンセルボタン(処理中のスレッドを中断)

### TranscribeWorker (QThread)
- 起動時に選択されたモデルの`WhisperModel`をロード
  - `device="cpu"`, `compute_type="int8"`
- `language="ja"`固定、`vad_filter=True`(無音区間をスキップし処理時間短縮)
- セグメントが生成されるたびにシグナルでメインスレッドへ送信
- キャンセル要求を受けたら安全にループを中断

### モデル管理
- 初回起動時、選択したモデルをHugging Face経由で自動ダウンロードし
  `~/.cache/huggingface`にキャッシュ(アプリ本体には同梱しない)
- ダウンロード中は進捗バーに「モデル取得中...」を表示
- ダウンロード失敗時(ネットワーク未接続等)はエラーダイアログ+リトライボタン

## データフロー

1. ユーザーがファイルをドロップ/選択する
2. ファイルパスを`TranscribeWorker`に渡してスレッドを開始する
3. faster-whisperがPyAV経由で音声をデコードし、セグメントごとに推論する
4. セグメントのテキストをメインスレッドにシグナルで送信し、`QTextEdit`に追記する
5. 完了後、全文をまとめて保存/コピー可能にする

## エラーハンドリング

| ケース | 挙動 |
|---|---|
| 非対応拡張子のファイルをドロップ | ドロップ時点で弾き、ダイアログでサポート形式を案内 |
| モデルダウンロード失敗 | エラーダイアログ表示 + リトライボタン |
| 処理中の例外(壊れたファイル等) | 例外をキャッチしてダイアログ表示、アプリ自体は継続動作 |
| 処理中のキャンセル | スレッドを安全に中断し、UIを初期状態に戻す |

## 開発・パッケージング

- 開発環境: Python仮想環境(`venv`) + `pip install faster-whisper pyside6`
- 第一段階はローカルでのスクリプト実行(`python main.py`)で動作確認
- 最終的に`PyInstaller`で`.app`化し、ダブルクリックで起動できるようにする
  (`.app`化は動作確認が済んだ後の後続タスクとする)
